SO₃lver is an extension of the package [FuzzifiED](https://docs.fuzzified.world). It enables exact diagonalization (ED) on the fuzzy sphere with the implementation of full SO(3) spatial rotation symmetry and some non-Abelian flavour symmetry through partitioning the Hilbert space into segments and compose these segments. The implementation of SO(3) symmetry greatly reduces the demand for the memory and enables calculation for much larger size.
